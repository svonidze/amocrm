```text





        В данном контексте мы рассмотрим ключевые аспекты, включая выбор каналов
        связи, установление регулярности взаимодействия, важность активного слушания

        и предоставление обратной связи. Также обсудим, как правильно формулировать

        Передача       Заказчика       из  отдела     продаж      в

        Производство


        Менеджер по продажам создает папку с проектной документацией на облачном

        диске, в которую входят бриф, спецификация и план работ. Эти документы
        прикрепляются к договору в виде ссылок, поэтому ответственность за их
        подготовку лежит на менеджере по продажам.


        Процесс передачи заказчика в производство, то есть в проектный отдел,
        начинается с сообщения менеджера по продажам в корпоративном чате "Генезис".

        Он уведомляет директора по продажам, проектного менеджера и тимлида о
        поступлении оплаты за услугу в канале "пв-общий". В сообщении менеджер

        указывает название компании, приобретенную услугу и количество часов/слотов
        (где 1 слот равен 20 часам), а также предоставляет ссылку на папку с проектной

        документацией.

        Проектный менеджер берет на себя ответственность за распределение проекта по
        определенной команде. Тимлид, в свою очередь, назначает конкретного

        бизнес-аналитика для работы над проектом. Вместе с ним он погружается в
        первичное описание брифа, изучает запись встречи пресейла и документацию от

        заказчика, если таковая имеется. В процессе они заполняют бриф первичной
        информацией, которая автоматически подгружается из карточки сделки в amoCRM,

        веденной менеджером по продажам до заключения сделки. Этот процесс
        автоматизации будет подробно рассмотрен в одном из модулей курса.

        Параллельно вышеописанным процессам менеджер по продажам должен создать

        канал коммуникации с заказчиком. Заказчик сам выбирает удобный для него канал
        общения, однако он должен иметь возможность для групповой коммуникации.
```
