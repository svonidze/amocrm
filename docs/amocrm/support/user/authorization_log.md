**Лог авторизаций и белый список IP-адресов**

В amoCRM доступны инструменты для контроля входов в аккаунт и ограничения доступа по IP-адресам.

Функционал доступен с тарифа «Расширенный».

**Лог авторизаций**

Лог авторизаций позволяет отслеживать входы пользователей и действия, связанные с доступом к аккаунту.

**Как открыть лог авторизаций**

1. Перейдите в раздел «Настройки» → «Пользователи».
2. Нажмите «Ещё» (три точки).
3. Выберите «Лог авторизаций».

**Какая информация отображается**

- дата и время входа;
- способ авторизации (web или API);
- экспортные действия;
- имя пользователя;
- страница, с которой выполнен вход;
- IP-адрес;
- используемый браузер.

Если в аккаунте используются интеграции, их активность также отображается в логе. В этом случае указывается пользователь, который подключил интеграцию.

**Белый список IP-адресов**

Белый список позволяет ограничить доступ к аккаунту только с определённых IP-адресов (например, с адресов офиса).

**Как настроить белый список**

1. Перейдите в раздел «Настройки» → «Пользователи».
2. Нажмите «Ещё» (три точки).
3. Выберите «Белый список IP-адресов».
4. Включите функцию.
5. Добавьте разрешённые IP-адреса.

**Важно**

По умолчанию в списке будет указан ваш текущий IP-адрес. Рекомендуется сохранить его, чтобы не потерять доступ к аккаунту.
