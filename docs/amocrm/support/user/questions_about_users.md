**Частые вопросы по пользователям и правам**

**Можно ли дать менеджеру право на объединение дублей?**

Да. Для этого у пользователя должны быть установлены права «Разрешено» на:

- просмотр;
- создание;
- редактирование;
- удаление.

Право на экспорт не требуется. Также учитываются особые права на этапы и поля.

**Можно ли настроить права сразу для группы пользователей?**

Да. Для этого создайте роль на основе прав пользователя и назначьте её другим сотрудникам.

**Можно ли скрывать отдельные поля?**

Да. С помощью опции Супер-поля можно настраивать отображение полей, включая их скрытие.

**Что происходит при смене ответственного?**

При смене ответственного в сделке система предложит также сменить ответственного у связанных:

- контактов;
- компании.

Аналогичное поведение действует для контактов, компаний и покупателей.

**Можно ли работать с задачами без прав на редактирование сделки?**

Да. Если у пользователя есть доступ на просмотр сделки, он может:

- ставить задачи;
- выполнять задачи;
- писать примечания;
- общаться в чате сделки.

**Можно ли добавить пользователя с email на кириллице?**

Нет. Добавление пользователей с кириллическим доменом email не поддерживается.

**Пропадут ли данные при удалении пользователя?**

Нет. Все данные сохраняются. При удалении система предложит назначить нового ответственного.

**Почему администратор не может изменить имя или пароль?**

Скорее всего, пользователь состоит в нескольких аккаунтах. В этом случае изменить имя и пароль может только сам пользователь в своём профиле.

**Как сменить администратора**

1. Войдите под текущим администратором.
2. Добавьте нового пользователя и назначьте его администратором.
3. Авторизуйтесь под новым администратором.
4. Удалите или деактивируйте прежнего администратора.

**Как работают особые права на этапы**

- особые права имеют приоритет над общими правами пользователя;
- если этап закрыт — сделки на нём не отображаются, даже при общем доступе;
- если доступ к сделкам закрыт, но открыт доступ к этапу — сделки на этом этапе будут видны.

**Почему пользователь видит сделки, хотя доступ закрыт**

Проверьте участников сделки:

- пользователь может быть добавлен как участник;
- или участником может быть его группа.

В этом случае пользователь сможет видеть такие сделки независимо от общих прав.
