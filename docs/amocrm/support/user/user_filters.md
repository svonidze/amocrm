**Поиск и фильтры пользователей**

Поиск пользователей доступен в разделе «Настройки» → «Пользователи» и используется для быстрого нахождения нужных сотрудников.

Функционал доступен только администратору аккаунта.

**Как работает поиск**

По умолчанию, без применения фильтров, отображаются все активные пользователи.

**Основные фильтры**

- **Активные пользователи** — отображаются только активные сотрудники;
- **Неактивные пользователи** — отображаются деактивированные пользователи;
- **Все пользователи** — отображаются все пользователи аккаунта;
- **Администраторы** — отображаются пользователи с правами администратора;
- **Бесплатные пользователи** — отображаются пользователи из группы бесплатных.

**Дополнительные фильтры**

**Группы**

- если фильтр не задан — отображаются пользователи всех групп;
- включая пользовательские группы и группу бесплатных пользователей.

**Роли**

- если фильтр не задан — отображаются пользователи с любыми ролями;
- при выборе роли «Администратор» отображаются только администраторы.

**Активность пользователей**

- если фильтр не задан — отображаются все пользователи;
- можно отфильтровать только активных или только неактивных пользователей.
