**Удаление и деактивация пользователя в amoCRM**

Если пользователь больше не работает в аккаунте, его можно удалить или временно отключить доступ.

**Как удалить пользователя**

1. Перейдите в раздел «Настройки» → «Пользователи».
2. Отметьте нужного пользователя галочкой слева.
3. Нажмите «Удалить».

При удалении система предложит передать данные пользователя другому сотруднику:

- контакты;
- компании;
- сделки;
- задачи.

**Деактивация пользователя**

Если нужно временно ограничить доступ, пользователя можно деактивировать.

- деактивированный пользователь не имеет доступа к аккаунту;
- его можно в любой момент снова активировать;
- если данные не переданы другому пользователю, они останутся закреплены за ним.

**Как деактивировать пользователя**

- откройте карточку пользователя;
- отключите параметр «Активность».

Чтобы вернуть доступ, включите параметр «Активность» снова.

**Важно**

Удалённые и деактивированные пользователи не занимают место в лимите аккаунта.
