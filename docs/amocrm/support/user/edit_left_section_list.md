**Настройка видимости разделов (левое меню)**

В amoCRM можно скрывать отдельные пункты левого меню для пользователей и ролей.

Раздел «Настройки» доступен только администраторам.

**Что можно настроить**

- скрыть пункты меню для всех пользователей (включая администраторов);
- настроить видимость для отдельных ролей.

**Настройка меню по ролям**

Для настройки используются те же роли, что и в разделе «Настройки» → «Пользователи».

- роль можно создать как в разделе пользователей, так и в настройках меню;
- после создания роль можно выбрать и настроить отображение пунктов меню.

**Как настроить видимость разделов**

1. Создайте или выберите роль в разделе «Настройки» → «Пользователи».
2. Перейдите в настройки пунктов левого меню.
3. Нажмите «+» и выберите нужную роль.
4. Отключите отображение нужных разделов (например, «Сделки», «Аналитика»).
5. Сохраните изменения.

После этого пользователи с выбранной ролью не будут видеть скрытые разделы.

**Важно**

- в этом разделе настраивается только видимость меню, а не права доступа;
- роль, созданная здесь, по умолчанию получает максимальные права;
- изменить права роли можно только в разделе «Пользователи».

**Удаление роли**

- удаление роли полностью выполняется только в разделе «Настройки» → «Пользователи»;
- кнопка «Удалить» в настройках меню удаляет только настройки отображения, а не саму роль.
