**Редактирование пользователя в amoCRM**

Пользователь может самостоятельно изменить свои данные в разделе «Профиль».

Администратор аккаунта может редактировать данные других пользователей и управлять их правами доступа.

**Какие данные можно изменить**

- имя пользователя;
- email (логин);
- пароль (если пользователь не состоит в других аккаунтах);
- права доступа.

**Как отредактировать пользователя**

1. Перейдите в раздел «Настройки» → «Пользователи».
2. Нажмите на имя нужного пользователя.
3. Внесите изменения.
4. Нажмите «Сохранить».

Важно: если пользователь состоит в нескольких аккаунтах, изменить его пароль из одного аккаунта не получится.
