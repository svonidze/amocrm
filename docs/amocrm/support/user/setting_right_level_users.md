**Права пользователей: уровни и взаимосвязь**

В amoCRM права доступа настраиваются отдельно для разных сущностей: сделок, контактов, компаний и задач.

**Уровни прав**

Для большинства сущностей доступны одинаковые уровни доступа:

- **Разрешено** — доступ ко всем объектам;
- **Все в группе** — доступ к объектам пользователей своей группы;
- **Если ответственный** — доступ только к своим объектам;
- **Запрещено** — доступ полностью отсутствует.

**Права для сделок**

- **Создание** — разрешено или запрещено;
- **Просмотр** — все сделки, в группе, только свои или запрещено;
- **Правка** — аналогично правам на просмотр;
- **Удаление** — аналогично правам на просмотр;
- **Экспорт** — аналогично правам на просмотр.

**Права для контактов и компаний**

Для контактов и компаний доступны те же типы прав:

- создание;
- просмотр;
- правка;
- удаление;
- экспорт.

Логика уровней прав полностью аналогична сделкам.

**Права для задач**

- **Правка** — редактирование задач (выполнение и закрытие задач не считаются правкой);
- **Удаление** — удаление задач с теми же уровнями доступа.

**Взаимосвязь прав**

Права внутри сущности связаны между собой.

Например:

- если запрещён просмотр сделок, автоматически становятся недоступны:
  - редактирование;
  - удаление;
  - экспорт.
- если запрещена правка, также недоступны удаление и экспорт.

Это связано с тем, что пользователь не может управлять объектами, которые не может просматривать.

**Важно**

Если пользователю разрешено создавать контакты или компании, но запрещён их просмотр, это может привести к созданию дубликатов.
