**Группы пользователей в amoCRM**

Группы пользователей позволяют объединять сотрудников и управлять доступом к данным внутри команды.

Создание, редактирование и удаление групп доступны начиная с расширенного тарифа.

**Особенности работы групп**

- каждый пользователь может состоять только в одной группе одновременно;
- группы используются, в том числе, для настройки прав доступа (например, «Все в группе»).

**Как создать группу**

1. Перейдите в раздел «Настройки» → «Пользователи».
2. Нажмите «Ещё» → «Добавить группу».
3. Укажите название группы.
4. Нажмите на зелёную галочку для сохранения.

В этом же разделе можно:

- изменить название существующей группы;
- удалить группу.

**Как добавить пользователя в группу**

1. Перейдите в раздел «Настройки» → «Пользователи».
2. Откройте карточку пользователя.
3. Выберите нужную группу.
4. Сохраните изменения.

**Важно**

Системную группу «Отдел продаж» нельзя переименовать или изменить.

При необходимости вы можете создать собственную группу с любым названием. Системная группа при этом может оставаться пустой.
