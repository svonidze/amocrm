**Настройка прав пользователей в amoCRM**

Права пользователей позволяют управлять доступом к данным, воронкам, почте и другим функциям системы.

**Как настроить права пользователя**

1. Перейдите в раздел «Настройки» → «Пользователи».
2. Нажмите на имя нужного пользователя.
3. Настройте необходимые права.
4. Нажмите «Сохранить».

**Доступ к почте**

Опция «Доступ к почте» определяет, какие ящики доступны пользователю.

- при включённой опции пользователь видит общие почтовые ящики;
- если отключить:
  - доступен только личный подключённый ящик;
  - общие ящики становятся недоступны;
  - в карточках письма из общих ящиков отображаются с сообщением о недостатке прав.

**Права на «Неразобранное» и этапы воронки**

Можно настроить отдельные права для:

- раздела «Неразобранное»;
- отдельных этапов воронки.

Для настройки:

- внизу списка прав нажмите «+»;
- выберите нужный этап;
- установите права доступа.

**Важно**

- если запретить просмотр этапа, пользователь будет видеть сам этап, но не будет видеть сделки в нём;
- чтобы закрыть доступ ко всей воронке, нужно настроить права для всех её этапов.

**Роли пользователей**

Роли позволяют назначать одинаковые права нескольким пользователям.

- создать роль можно через «+» → «Создать новую роль»;
- роль создаётся на основе текущих прав пользователя.

**Управление ролями**

- изменить роль можно через значок карандаша;
- если изменить права без редактирования роли, пользователю будут назначены индивидуальные права;
- удалить роль можно через значок корзины.

При удалении роли система предложит:

- сохранить пользователям индивидуальные права;
- или назначить другую роль.

**Права на списки**

Для каждого списка можно настроить отдельные права доступа:

- разрешено;
- запрещено;
- внутри сделки.

**Как работает режим «Внутри сделки»**

- раздел списка недоступен, но связанные элементы отображаются в карточке;
- права на просмотр, редактирование и удаление зависят от прав на основную сущность;
- если доступ к списку запрещён, вкладка не отображается в карточке.

**Важно**

- создавать, редактировать и удалять списки может только администратор;
- для новых списков всем пользователям (кроме администратора) по умолчанию устанавливается доступ «Запрещено».

**Для разработчиков**

Права на списки доступны также через API пользователей и ролей.
