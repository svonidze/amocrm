**Добавление пользователей в amoCRM**

Добавлять пользователей в аккаунт может только администратор.

**Как создать пользователя**

1. Перейдите в раздел «Настройки» → «Пользователи».
2. Нажмите «Добавить пользователя» в правом верхнем углу.
3. Заполните необходимые данные и сохраните изменения.

После создания пользователю на электронную почту придёт письмо со ссылкой для входа в аккаунт и установки пароля.

Важно: при редактировании уже существующего пользователя письмо с изменёнными данными не отправляется.

**Если пользователь уже зарегистрирован в другом аккаунте**

При добавлении может появиться сообщение: «Этот email уже зарегистрирован. Введите другой email или добавьте почту».

- пользователя всё равно можно добавить в аккаунт;
- задать новое имя и пароль при добавлении не получится;
- пароль для входа останется прежним.

**Ошибка «Пользователь уже добавлен»**

Если система сообщает, что пользователь уже добавлен, но его нет в списке:

- проверьте фильтр по неактивным пользователям;
- возможно, пользователь уже есть в аккаунте, но деактивирован.

**Если пользователь забыл пароль**

1. Перейдите на страницу входа.
2. Нажмите «Забыли пароль».
3. Введите email (логин).
4. Перейдите по ссылке из письма и задайте новый пароль.

После этого пользователь сможет войти в аккаунт с новым паролем.
