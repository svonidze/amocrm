**Мониторинг активности пользователей**

Мониторинг активности позволяет ограничивать действия пользователей в аккаунте и контролировать объём просматриваемых данных.

Функционал доступен на профессиональном тарифе.

**Как работает мониторинг**

Вы можете задать лимиты на действия пользователей. При их превышении пользователь автоматически деактивируется и не сможет войти в аккаунт до повторной активации.

Администраторы получают уведомление с информацией о пользователе и причине деактивации.

**Какие ограничения можно настроить**

- на просмотр карточек;
- на просмотр элементов списков.

**Кто может настраивать**

- только администратор аккаунта.

**На кого распространяются ограничения**

- на всех пользователей аккаунта.

**Как снова активировать пользователя**

1. Перейдите в раздел «Настройки» → «Права и пользователи».
2. Откройте список деактивированных пользователей.
3. Выберите нужного пользователя.
4. Включите параметр «Активность».
5. Сохраните изменения.

**Ограничения на просмотр карточек**

Учитывается просмотр карточек:

- сделок;
- покупателей;
- контактов;
- компаний.

Засчитывается только первый вход в карточку.

Пример: если открыть одну карточку, затем другую и снова вернуться к первой — будет засчитано 2 просмотра.

**Ограничения на просмотр списков**

Ограничение распространяется на списки:

- сделок (все воронки);
- покупателей;
- контактов;
- компаний;
- объединённого списка контактов и компаний.

Подсчёт ведётся по элементам списка:

- на одной странице учитывается до 50 элементов;
- лимит суммируется по всем сущностям.

Пример: если открыть список покупателей (50 элементов), затем список сделок (ещё 50), будет засчитано 100 просмотров.

**Что учитывается в списках**

- переходы между списками разных сущностей;
- переходы между страницами внутри списка;
- результаты фильтров, поиска, пресетов и тегов.

Каждая новая выборка добавляет до 50 элементов к счётчику.

**Экспорт**

Экспорт данных не учитывается в мониторинге, если пользователю разрешён экспорт.

**API и мобильные приложения**

- **API** — учитываются все запросы к методу /list;
- **Мобильные приложения** — все действия считаются как просмотр элементов списка.

**Важно**

Для корректной работы мониторинга рекомендуется использовать актуальную версию мобильного приложения.
