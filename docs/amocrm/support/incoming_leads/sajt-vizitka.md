**Сайт-визитка**

Сайт-визитка — это простой лендинг внутри amoCRM, который можно создать без навыков программирования.

**Как создать**

1. Перейдите в «Сделки» → «Настройки воронки»;
2. Нажмите «Добавить источник»;
3. Выберите «Сайт-визитка»;
4. Настройте страницу и сохраните.

**Редактор**

В редакторе доступны:

- добавление и редактирование блоков;
- настройка отступов и размеров;
- кнопки (телефон, email);
- изображения и логотип;
- разделители;
- веб-форма;
- сортировка элементов.

**Отображение**

- можно отдельно настроить мобильную и web-версию.

**Ссылка на сайт**

После создания можно отправить клиенту ссылку:

- из настроек воронки;
- из карточки сделки («…» → «Клиентская ссылка»);
- из раздела «Статистика».

**Особенности**

- в одной воронке доступна только одна сайт-визитка;
- ссылка в карточке доступна, если сделка и визитка в одной воронке;
- для использования мессенджеров их нужно подключить заранее.

**Работа с мессенджерами**

- можно добавить кнопки мессенджеров;
- настраивается текст сообщения для клиента.
