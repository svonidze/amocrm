**Контроль дублей**

Функция контроля дублей позволяет автоматически находить повторные заявки и управлять ими.

**Как включить**

1. Перейдите в «Сделки» → «Настройки воронки»;
2. Включите тумблер «Контроль дублей»;
3. Откройте настройки правил.

**Что можно настроить**

- источники для проверки;
- параметры поиска дублей;
- действия при обнаружении.

**Источники**

- с полной поддержкой настроек;
- с ограниченной поддержкой (через BIG DATA).

**Параметры поиска дублей**

- **BIG DATA** — анализ с использованием алгоритмов;
- **Пиксель** — по взаимодействию клиента с сайтом;
- **Email** — по совпадению почты;
- **Телефон** — по номеру;
- **Дополнительные поля** — текстовые и числовые.

**Особенности проверки**

- для чатов проверка происходит сразу;
- для других источников — после создания заявки;
- объединение возможно, если одна из заявок в «Неразобранном».

**Настройка области поиска**

- выбор воронок;
- выбор этапов;
- остальные сделки не участвуют в проверке.

**Поведение при конфликте данных**

- обновить существующую сделку новыми данными;
- оставить текущие данные без изменений.

**Действия при обнаружении дубля**

Если найдено до 3 дублей:

- обновить все сделки;
- обновить самую новую;
- создать новую сделку.

**Важно:** если найдено более 3 дублей — объединение не выполняется.

**После объединения**

- можно автоматически создать задачу;
- задача добавляется в найденные сделки.

**Дополнительные особенности**

- пиксель работает только для CRM Plugin и сайта;
- идентификация возможна по браузеру;
- событие объединения фиксируется при использовании BIG DATA или пикселя.
