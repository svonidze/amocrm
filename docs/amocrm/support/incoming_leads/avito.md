**Интеграция с Avito**

Интеграция с Avito позволяет получать обращения по объявлениям напрямую в amoCRM и обрабатывать их в одном интерфейсе.

**Как подключить**

1. Перейдите в «Сделки» → «Настроить воронку»;
2. В разделе «Источники сделок» нажмите «Добавить»;
3. Выберите Avito;
4. Введите ID пользователя и секретный ключ;
5. Сохраните настройки.

**Как работает интеграция**

- новые сообщения из Avito создают заявки;
- заявки попадают в этап «Неразобранное»;
- название заявки — это название объявления.

**Автоматическое подключение объявлений**

- включите опцию автоподключения;
- новые объявления будут добавляться автоматически.

**Важно:** объявления должны быть активными.

**Работа с заявками**

- привязка к сделке или покупателю;
- обработка как обычного чата;
- переписка ведётся в карточке.

**Особенности**

- можно писать клиенту из amoCRM даже после удаления чата в Avito;
- если объявление архивировано — оно становится недоступным;
- новые объявления появляются в списке после первой заявки.

**Ограничения**

- передаются только текстовые сообщения;
- файлы и видео не поддерживаются;
- личные сообщения не передаются;
- прочтение в amoCRM не влияет на статус в Avito;
- кнопки в сообщениях не отображаются.
