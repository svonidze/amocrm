**Форма для сайта и «Неразобранное»**

Вы можете подключить форму обратной связи и получать заявки напрямую в amoCRM.

**Как подключить форму**

1. Перейдите в раздел «Сделки»;
2. Нажмите на значок настроек;
3. Выберите «Добавить источник»;
4. Выберите «Форма для сайта»;
5. Настройте форму.

**Конструктор формы**

Состоит из трёх разделов:

**1. Редактор полей**

- добавление полей для клиента;
- настройка внешнего вида формы.

**2. Настройка формы**

- название формы;
- добавление тегов;
- выбор этапа (включая «Неразобранное»).

**3. Размещение**

- создание отдельной страницы;
- получение ссылки;
- встраивание на сайт.

**Работа с «Неразобранным»**

- если выбран этот этап — заявки попадают туда;
- после обработки можно создать сделку.

**Что создаётся при принятии заявки**

- сделка;
- контакт;
- компания.

Создаются все сущности, которые можно сформировать из данных формы.

**Что происходит при отклонении**

- также создаются сущности (если возможно);
- они перемещаются в удалённые.

**Передача данных**

- все заполненные поля автоматически переносятся в amoCRM.

**Отправка через мессенджеры**

- можно включить отправку через Viber или WhatsApp;
- данные формы подставляются в сообщение автоматически.

**Важно:**

- для Viber на ПК требуется установленное приложение;
- иначе используйте стандартную отправку формы.
