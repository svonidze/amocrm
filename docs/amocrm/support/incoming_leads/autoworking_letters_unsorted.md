**Автообработка писем (парсер email)**

Автопочта — это инструмент обработки входящих писем, который позволяет автоматически создавать сделки и заполнять поля на основе содержимого письма.

**Как работает парсер**

- обрабатывает входящие шаблонные письма;
- извлекает данные из текста;
- заполняет поля в карточках сделки, контакта или компании.

**Где настроить**

1. Перейдите в раздел «Сделки»;
2. Откройте «Настроить воронку»;
3. В источниках выберите «Автообработка писем».

**Настройка подключения**

Подключение состоит из 4 шагов:

**1. Выбор почтовой службы**

- выберите почтовый сервис (например, Gmail или Yandex);
- настройте пересылку писем на служебный адрес amoCRM.

**2. Подтверждение пересылки**

- нажмите «Далее»;
- перейдите по ссылке из письма для подтверждения.

**3. Выбор типового письма**

- укажите пример письма, по которому будет выполняться обработка.

**4. Настройка правил**

- выделите значения в тексте письма;
- сопоставьте их с полями в системе.

**Какие данные можно заполнять**

- поля сделки;
- поля контакта;
- поля компании.

**Дополнительные настройки**

- назначение ответственного;
- установка тегов;
- выбор этапа сделки;
- автоматическое создание задачи.

**Важно:** необходимые поля должны быть заранее созданы в настройках карточек.
