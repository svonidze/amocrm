**Чат ВКонтакте в «Неразобранном»**

Интеграция с ВКонтакте позволяет получать сообщения клиентов из группы и обрабатывать их прямо в amoCRM.

**Как подключить**

1. Перейдите в «Сделки» → «Настроить воронку»;
2. Нажмите «Добавить источник»;
3. Выберите «ВКонтакте»;
4. Авторизуйтесь;
5. Нажмите «Добавить группу»;
6. Выберите нужную группу и подключите её.

**Важно:** у профиля администратора должен быть подтверждён email.

**Как работает интеграция**

- сообщения из группы поступают в amoCRM;
- новые обращения попадают в «Неразобранное»;
- переписка ведётся внутри системы.

**Работа с заявкой**

- принять — для нового клиента;
- привязать — к существующей сделке или покупателю;
- отклонить — если это спам.

**Если клиент уже есть**

- сообщение автоматически попадёт в существующую карточку;
- общение продолжится в ней.
