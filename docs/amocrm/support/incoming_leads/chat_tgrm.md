**Чат Telegram в «Неразобранном»**

Интеграция с Telegram позволяет получать сообщения клиентов через чат-бота и обрабатывать их прямо в amoCRM.

**Как подключить**

1. Перейдите в «Сделки» → «Настройки воронки»;
2. Нажмите «Добавить источник»;
3. Выберите Telegram;
4. Нажмите «Установить»;
5. Введите API Token бота;
6. Сохраните настройки.

**Как получить API Token**

**Если бот уже есть**

- откройте Telegram и найдите @BotFather;
- введите команду /mybots;
- выберите бота;
- скопируйте API Token.

**Если бота нет**

- в @BotFather введите /newbot;
- укажите имя и username;
- получите API Token;
- используйте его для подключения.

**Как работает интеграция**

- клиент пишет боту;
- в amoCRM создаётся заявка;
- она попадает в «Неразобранное».

**Работа с заявкой**

- принять — для нового клиента;
- привязать — к существующей сделке;
- отклонить — если это спам.
