**CRM Plugin (кнопка обратной связи)**

CRM Plugin — это виджет (кнопка) для сайта, который позволяет клиентам связаться с вами через мессенджеры и чат, а заявки автоматически попадают в amoCRM.

**Поддерживаемые каналы**

- ВКонтакте;
- Telegram;
- WhatsApp;
- Viber;
- WeChat;
- Онлайн-чат;
- другие каналы связи.

**Возможности**

- создание кнопки для сайта;
- настройка внешнего вида;
- подключение каналов связи;
- получение кода для установки на сайт;
- использование ботов и автоматизаций.

**Как подключить**

1. Перейдите в «Сделки» → «Настроить воронку»;
2. Нажмите «Добавить источник»;
3. Выберите «CRM Plugin»;
4. Подключите нужные каналы;
5. Сохраните настройки.

**Как работает**

- клиент выбирает канал на сайте;
- отправляет сообщение;
- в amoCRM создаётся заявка в «Неразобранном».

Далее вы можете:

- принять заявку;
- привязать к существующей сделке;
- отклонить.

**Если клиент уже есть в системе**

- сообщение попадёт в существующую карточку сделки или покупателя.

**Какие данные передаются**

- имя клиента;
- источник обращения;
- действия на сайте (просмотры, время, страницы).

**Важно:** данные о поведении передаются только при первом обращении.

**Онлайн-чат**

- встроенный канал общения на сайте;
- настраивается в CRM Plugin;
- поддерживает автоматические сообщения.

**Автоматическое приветствие**

- бот может отправлять сообщение посетителю;
- настраиваются условия:

- время на сайте;
- прокрутка страницы;
- количество посещённых страниц;
- переход на конкретную страницу.

**Маркеры**

- {{lead.responsible}} — ответственный;
- {{contact.name}} — имя клиента.

Маркеры работают при повторных обращениях.

**Ключевые действия**

- установка тегов;
- запуск триггеров;
- показ формы на сайте.

**Установка на сайт**

- укажите адрес размещения;
- скопируйте код;
- вставьте его в HTML внутри тега <body>.

**Особенности**

- можно создать несколько кнопок для разных сайтов;
- в рамках одной воронки используется общий сценарий бота;
- изменения бота применяются ко всем кнопкам этой воронки.

**Дизайн кнопки**

- настройка цвета, размера и положения;
- выбор формы (круглая, квадратная, с закруглением);
- анимация и поведение при открытии.
