**Онлайн-чат**

Онлайн-чат — это инструмент для общения с клиентами на сайте или в приложении, который позволяет быстро отвечать на вопросы и обрабатывать обращения.

**Где настроить**

- раздел «Настройки» → «Чаты и мессенджеры» → «Онлайн-чаты».

**Что отображается в списке**

- **CRM Plugin** — кнопки, к которым подключён чат;
- **Сайт-визитка** — страницы, где используется чат;
- **Беседы** — формат общения с клиентом.

**Форматы бесед**

**Одна активная**

- все сообщения идут в один диалог.

**Множественные**

- клиент может создавать несколько диалогов;
- каждой беседе присваивается номер;
- можно завершать беседы;
- история сохраняется в карточке.

**Установка на сайт**

- нажмите «Настроить»;
- укажите адрес сайта;
- скопируйте скрипт;
- вставьте в HTML-код сайта.

**Для приложения**

- включите режим «Встраивается в приложение»;
- скопируйте скрипт без привязки к URL.

**Внешний ID**

- позволяет идентифицировать клиента;
- передаётся через API;
- сохраняет историю переписки между устройствами.

**Онлайн-чат в сайт-визитке**

- добавляется через редактор;
- можно изменить внешний вид кнопки;
- настраиваются текст, цвет и стиль.

**Важно:**

- для работы чата необходимо указать адрес размещения;
- все переписки сохраняются в карточке сделки или покупателя.
