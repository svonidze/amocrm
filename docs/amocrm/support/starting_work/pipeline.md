**Настройка воронки продаж**

При создании аккаунта в amoCRM автоматически создаётся стандартная воронка продаж с базовыми этапами. Вы можете изменить её полностью или адаптировать под свой бизнес.

**Зачем настраивать этапы**

Воронка помогает отслеживать движение сделок и анализировать эффективность продаж. Система автоматически собирает статистику по каждому этапу:

- конверсия между этапами — сколько сделок переходят дальше;
- среднее время нахождения сделки на этапе;
- общая динамика продаж.

На основе накопленных данных система может строить прогноз продаж.

**Автоматизация этапов**

Для каждого этапа можно настроить автоматические действия с помощью Digital Pipeline (Цифровой воронки):

- постановка задач;
- отправка писем;
- отправка SMS;
- другие автоматические сценарии.

**Как перейти к настройке воронки**

1. Откройте раздел «Сделки»;
2. Нажмите кнопку «Настроить» в правом верхнем углу;
3. Перейдите в режим редактирования воронки.

**Как настроить этапы**

- добавить этап — нажмите кнопку «+»;
- изменить этап — кликните по нему и отредактируйте название или цвет;
- переместить этап — используйте drag-and-drop;
- удалить этап — перетащите его в корзину в правом нижнем углу.

**Важно:** финальные этапы «Успешно реализовано» и «Закрыто и не реализовано» удалить нельзя, но их можно переименовать.

**Несколько воронок**

Если у вас несколько направлений бизнеса, вы можете создать отдельные воронки.

- нажмите на название воронки в левом верхнем углу;
- выберите создание новой воронки или редактирование существующей.

**Создание первой сделки**

Сделку можно создать несколькими способами:

- кнопка «Новая сделка» в разделе «Сделки»;
- быстрое добавление прямо в воронке;
- из карточки контакта или компании.

**Как заполнить карточку сделки**

Карточка состоит из двух частей:

- левая часть — данные сделки, контакт и компания;
- правая часть — лента событий (история действий, задачи, звонки, сообщения).

Для создания сделки:

1. Нажмите «Новая сделка»;
2. При необходимости заполните название (или оставьте пустым — оно создастся автоматически);
3. Укажите бюджет;
4. Добавьте контакт;
5. Сохраните сделку.

**Работа со сделкой в воронке**

После создания сделка появится в воронке. Вы можете перемещать её между этапами с помощью drag-and-drop.

**Аналитика по воронке**

Все изменения автоматически отражаются в отчётах:

- перейдите в раздел «Аналитика»;
- откройте отчёт «Анализ продаж».

В отчёте вы увидите воронку с этапами и показатели конверсии по каждому из них.

**Рекомендации**

- на начальном этапе используйте только ключевые стадии;
- добавляйте новые этапы по мере необходимости;
- регулярно анализируйте конверсию и длительность этапов;
- используйте автоматизацию для ускорения работы с клиентами.
