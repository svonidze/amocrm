**Цифровая воронка (Digital Pipeline)**

Цифровая воронка позволяет автоматизировать работу со сделками: система выполняет действия без участия менеджера в зависимости от этапа и условий.

**Доступность**

Настройка Digital Pipeline доступна на тарифе «Расширенный» и выше.

**Как перейти к настройке**

1. Перейдите в раздел «Сделки»;
2. Нажмите «Настроить»;
3. Выберите нужную воронку (если их несколько);
4. Откройте сценарий Digital Pipeline.

**Доступные действия**

Для каждого этапа можно настроить автоматические действия:

- создание задачи;
- создание сделки или покупателя;
- отправка письма;
- запуск Salesbot;
- добавление в Google Analytics;
- отправка Webhook;
- смена этапа сделки;
- добавление тегов.

**Пример настройки сценария**

**Создание задачи**

- выберите ячейку под нужным этапом;
- укажите действие «Создать задачу»;
- задайте условие «при переходе в этап»;
- установите срок выполнения (например, сразу);
- назначьте ответственного (текущий ответственный).

**Отправка письма**

- предварительно подключите почту и создайте шаблон;
- выберите действие «Отправить письмо»;
- укажите почтовый ящик и шаблон;
- задайте условие выполнения.

**Интеграция с рекламой**

Вы можете автоматически добавлять контакты в рекламные аудитории:

- выберите действие интеграции (например, VK);
- авторизуйтесь в аккаунте;
- укажите рекламную кампанию и объявление;
- при выходе из этапа можно настроить удаление из аудитории.

**Автоматическая смена этапа**

Сделка может автоматически переходить между этапами по событиям, например:

- после посещения сайта;
- после входящего сообщения или звонка;
- по таймеру.

Для этого:

- выберите действие «Смена статуса»;
- укажите условие (например, «После захода на сайт»);
- добавьте сайт и разместите код отслеживания.

**Условия выполнения действий**

Каждое действие можно ограничить условиями:

- теги;
- ответственный;
- бюджет сделки;
- пользовательские поля.

Например, можно выполнить действие только для сделок с источником «сайт».

**Триггеры запуска**

Действия могут выполняться:

- при переходе между этапами;
- при создании сделки;
- при входящем письме, звонке или сообщении;
- через заданное время или регулярно.

**Результат работы**

После настройки сценария система автоматически выполняет действия:

- ставит задачи менеджерам;
- отправляет сообщения клиентам;
- обновляет этапы сделок;
- запускает интеграции и аналитику.

**Важно:** автоматизация работает только при корректно настроенных условиях и подключённых интеграциях.
