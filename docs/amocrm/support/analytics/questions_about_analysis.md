**Частые вопросы по аналитике**

**Почему сделка не попадает в отчёт после смены статуса?**

- дата закрытия фиксируется при первом закрытии;
- повторная смена статуса не меняет дату автоматически.

**Что делать в таком случае**

- создать новую сделку;
- или вернуть старую в открытый этап и снова закрыть.

**Почему данные в разных отчётах отличаются?**

- в «Отчёте по сотрудникам» учитываются сделки, созданные пользователем;
- в «Анализе продаж» — также сделки, переданные менеджеру.

**Как учитывается перенос сделки между воронками**

- при создании новой сделки — считаются как разные сделки;
- при переносе — учитывается только в новой воронке.

**Можно ли ставить цели по воронкам?**

- нет, цели задаются по менеджерам, количеству или бюджету.

**Можно ли очистить аналитику?**

- только через удаление всех данных аккаунта;
- счётчик «Неразобранного» не обнуляется.

**В какой период попадает сделка?**

- в цели учитываются только закрытые сделки;
- дата — момент закрытия сделки.

**Почему при клике на этап показываются другие статусы?**

- отображаются все сделки, проходившие через этап;
- не только текущие.

**Как узнать текущие сделки на этапе?**

- используйте «Сводный отчёт».

**Можно ли экспортировать аналитику?**

- на данный момент экспорт недоступен.
