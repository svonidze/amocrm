**Аналитика по звонкам**

Раздел «Звонки» позволяет анализировать входящие и исходящие звонки всех менеджеров.

**Доступность**

- доступен на тарифах «Расширенный» и «Профессиональный».

**Что отображается**

- количество звонков;
- длительность звонков;
- сравнение между менеджерами;
- сравнение со средними значениями.

**Формат длительности**

- ЧЧ:ММ:СС (часы, минуты, секунды).

**Фильтрация**

- дата звонка;
- контакты или компании;
- ответственный менеджер;
- длительность звонка;
- статус звонка.

**Итоговые показатели**

**Среднее**

- рассчитывается как:

Итого / количество менеджеров

**Итого**

- общее количество входящих звонков;
- общее количество исходящих звонков;
- суммарное количество звонков.

**Какие звонки учитываются**

- только звонки, привязанные к карточкам;
- без контакта звонок не попадёт в отчёт;
- звонки из «Неразобранного» отображаются в событиях.

**Какие данные передаются**

- тип звонка (входящий / исходящий);
- количество;
- результаты звонков.

**Особенности**

- данные обновляются после передачи от телефонии;
- звонки из приложения фиксируются без записи;
- после смены тарифа доступны старые данные.

**Если раздел недоступен**

- используйте «Аналитика» → «Список событий»;
- отфильтруйте входящие и исходящие звонки.
