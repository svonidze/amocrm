**Цели**

Раздел «Цели» позволяет контролировать выполнение планов продаж и отслеживать эффективность команды.

**Доступность**

- тарифы «Расширенный» и «Профессиональный»;
- настройка доступна только администраторам.

**Где находится**

- Аналитика → Цели.

**Настройка целей**

- включение целей;
- выбор периода:

- месяц;
- квартал;
- год.

- указание периода действия целей.

**Установка целей**

- для каждого менеджера:

- целевой бюджет;
- целевое количество сделок.

- возможна установка для групп;
- значения распределяются между участниками.

**Как рассчитывается выполнение**

- учитываются только сделки со статусом «Успешно реализовано».

**Отображение прогресса**

- **зелёный** — цель выполняется или перевыполнена;
- **красный** — отставание от плана или нет прогресса.

**Фильтры**

- по бюджету;
- по количеству сделок;
- по ответственным;
- по периоду.

Раздел помогает планировать продажи и контролировать выполнение KPI.
