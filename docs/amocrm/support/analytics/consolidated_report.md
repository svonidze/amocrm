**Сводный отчёт**

Сводный отчёт — это раздел аналитики, который показывает общую статистику по сделкам, контактам, покупкам и задачам.

**Фильтры**

- дата создания или закрытия;
- статус сделки;
- ответственный менеджер;
- пользовательские поля;
- теги.

**График активности**

- показывает количество созданных сделок;
- отображает «Новые» и «Выигранные» сделки;
- можно сегментировать по дням, неделям, месяцам.

**Блок «Сделки»**

- количество сделок на этапах;
- суммарный бюджет;
- процент от общего количества;
- отображаются только этапы с активными сделками.

**Сделки по менеджерам**

- количество сделок;
- сумма бюджета;
- доля в процентах;
- доступен переход к списку сделок.

**Блок «Покупки»**

- совершённые покупки;
- запланированные на 7 дней;
- не совершённые покупки.

**Покупки по менеджерам**

- количество покупок;
- сумма;
- процент от общего числа;
- средний чек.

**Блок «Контакты»**

- общее количество контактов и компаний;
- процентное соотношение;
- переход к спискам по клику.

**Контакты по менеджерам**

- количество контактов;
- процент от общего числа.

**Блок «Задачи»**

- общее количество задач;
- распределение по типам;
- задачи по менеджерам.

**Особенности**

- данные отображаются в виде графиков и диаграмм;
- по клику можно перейти к детализации;
- фильтры применяются ко всем блокам (кроме первого графика сделок).
