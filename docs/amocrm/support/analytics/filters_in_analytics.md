**Фильтры в аналитике**

В разных разделах аналитики amoCRM доступны собственные фильтры и режимы отображения данных.

**Анализ продаж**

- **По статусу:**

- Все;
- Активные;
- Закрытые.

- **По бюджету** — процент от общей суммы сделок;
- **По количеству** — процент от общего числа сделок;
- дополнительные пользовательские фильтры.

**Сводный отчёт**

- группировка по:

- дням;
- неделям;
- месяцам.

- фильтры:

- по дате (создания или закрытия);
- по статусу сделки;
- по менеджеру;
- по тегам.

**Отчёт по сотрудникам**

- выбор периода;
- сравнение менеджеров;
- переход к детальной статистике.

**Список событий**

- по дате;
- по автору;
- по объекту (сделка, контакт и др.);
- по типу события;
- по значениям до и после изменений.

**Звонки**

- **Режимы:**

- по количеству;
- по длительности;
- по типу (входящие / исходящие).

- **Фильтры:**

- по дате;
- по сущности;
- по менеджеру;
- по длительности;
- по статусу звонка.

**Цели**

- **Режимы:**

- по бюджету;
- по количеству.

- **Фильтры:**

- менеджеры;
- месяц и год.

Фильтры позволяют гибко настраивать аналитику под задачи бизнеса.
