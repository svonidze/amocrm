Дата сохранения: 2026-10-08.
Формат: текст официальной страницы, автоматически преобразованный в Markdown.

**Список событий**

Список событий — это раздел аналитики, в котором отображаются все действия в системе.

**Что отслеживается**

- сделки;
- покупатели;
- контакты;
- компании;
- задачи;
- списки.

**Структура таблицы**

- **Дата** — время события;
- **Автор** — пользователь или система;
- **Объект** — сущность (сделка, контакт и др.);
- **Название** — имя объекта;
- **Событие** — тип действия;
- **До / После** — изменения значений.

**Особенности автора**

- может быть пользователь;
- робот (автоматизация);
- интеграция или Salesbot.

**Навигация**

- клик по объекту открывает карточку;
- быстрый переход к нужной сущности.

**Фильтрация**

- по дате;
- по объекту;
- по менеджеру;
- по типу события;
- по значениям до и после.

Фильтры можно применять через колонку или общие настройки.

**Отображение**

- от 25 до 200 событий на странице;
- переключение страниц — внизу списка.

Раздел помогает анализировать изменения и контролировать действия в системе.
