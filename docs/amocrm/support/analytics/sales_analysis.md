**Анализ продаж**

Раздел «Анализ продаж» позволяет отслеживать движение сделок, конверсию и эффективность работы менеджеров.

**Фильтры**

- период;
- ответственный менеджер;
- воронка;
- теги и дополнительные поля (для отдельных графиков).

**Первый график (движение сделок)**

- показывает переходы между этапами;
- верхние цифры — количество сделок на этапе;
- стрелки — количество переходов между этапами;
- нижние цифры — потерянные сделки.

**Особенности**

- созданные сразу на этапе сделки не учитываются в переходах;
- при возврате сделки значение уменьшается;
- если сделка проходит несколько этапов — учитывается во всех переходах.

**Дополнительно**

- показатель «Новые» — все созданные сделки (кроме «Неразобранного»);
- последний блок — успешно закрытые сделки.

**Второй график (конверсия)**

- показывает процент перехода между этапами;
- первый этап = 100%;
- можно анализировать по количеству или бюджету.

**Фильтры второго графика**

- все сделки;
- активные;
- закрытые.

**Средняя продолжительность сделки**

- время нахождения на этапах;
- рассчитывается как:

общее время на этапе / количество сделок

**Неразобранное**

- среднее время обработки заявок;
- количество входящих заявок;
- количество переведённых в сделки.

**Прогноз продаж**

- прогноз количества сделок;
- ожидаемая сумма продаж;
- рассчитывается автоматически на основе истории.

**Что учитывается в прогнозе**

- текущее количество сделок;
- успешные сделки;
- потерянные сделки;
- бюджет.

Раздел помогает анализировать эффективность продаж и планировать результаты.
