**Экспорт и синхронизация задач**

Вы можете экспортировать задачи и синхронизировать их с внешними календарями.

**Экспорт задач**

- доступен в формате iCal (iCalendar);
- подходит для работы с календарями и планировщиками;
- поддерживается в различных сервисах, включая Microsoft Outlook.

**Синхронизация с Google Календарём**

Вы можете подключить двустороннюю синхронизацию:

1. Перейдите в раздел «Задачи»;
2. Нажмите «Синхронизировать»;
3. Выберите аккаунт Google;
4. Разрешите доступ.

После подключения:

- в Google Календаре появится календарь вида «amoCRM - domain»;
- синхронизируются задачи за последний месяц;
- изменения обновляются в обе стороны.

**Что можно редактировать в Google Календаре**

- дату задачи;
- название;
- описание.

**Ограничение:** тип задачи изменить нельзя.

**Привязка задачи к сущности**

Вы можете связать задачу с карточкой amoCRM через ID:

- добавьте в описание задачи запись вида #123456789;
- ID берётся из ссылки на карточку.

После этого в задаче появится ссылка на сделку, контакт, компанию или покупателя.

**Синхронизация при изменениях**

- если задача выполнена в amoCRM — она удаляется из Google Календаря;
- если задача удалена в Google Календаре — в amoCRM она отмечается как выполненная;
- если задача удалена в amoCRM — в календаре она остаётся.

**Важно:** импорт задач в систему не поддерживается.
