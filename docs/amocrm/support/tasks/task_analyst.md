**Аналитика и статистика по задачам**

В amoCRM доступно несколько разделов, где можно анализировать задачи и контролировать работу менеджеров.

**Сводный отчёт**

- общее количество задач в аккаунте;
- распределение по типам задач;
- распределение по ответственным;
- фильтрация по датам создания и выполнения.

**Отчёт по сотрудникам**

Показывает задачи по каждому менеджеру:

- в работе;
- новые;
- просроченные;
- завершённые;
- завершённые с результатом.

Данные отображаются за выбранный период.

**Список событий**

- фильтрация по событиям «Завершение задачи»;
- фильтрация по «Результат по задаче»;
- возможность указать период и ответственных.

**Статистика в воронке сделок**

В режиме «Воронка» доступна панель статистики:

- задачи на сегодня;
- сделки без задач;
- просроченные задачи;
- задачи за сегодня и вчера.

Вы можете нажать на показатели, чтобы отфильтровать сделки.

**Статистика в карточке сделки**

- отображается во вкладке «Статистика»;
- показывает активность по задачам;
- учитывает задачи в сделке, а также в связанных контактах и компаниях.
