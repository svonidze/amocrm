**Автоматические действия с задачами**

В amoCRM вы можете настроить автоматическое создание и управление задачами с помощью Digital Pipeline, Salesbot, бизнес-процессов и других инструментов.

**Автоматическое создание задач в сделках**

В разделах «Сделки» и «Покупатели» задачи можно создавать автоматически через Digital Pipeline.

**Что можно настроить**

- условия запуска (например, наличие тега или ответственного);
- событие запуска (переход на этап, создание сделки, изменение поля и др.);
- время выполнения (сразу, через заданный интервал или в конкретное время);
- ответственного за задачу;
- тип задачи;
- текст задачи.

**Варианты триггеров**

- при создании или переходе на этап;
- при смене ответственного;
- при добавлении или удалении тега;
- при изменении поля;
- при входящем сообщении, звонке или письме;
- при взаимодействии клиента (например, прочтении сообщения);
- по расписанию или с задержкой;
- циклически.

**Срок выполнения задачи**

- сразу;
- в конце дня;
- через день, 3 дня или неделю;
- через заданный интервал (дни, часы, минуты).

**Автоматические задачи через Salesbot**

- добавьте шаг «Создать задачу» в сценарии;
- задайте параметры и сохраните бота.

**Автоматические задачи в контактах и компаниях**

Можно настроить через бизнес-процессы:

1. Перейдите в «Контакты и компании»;
2. Нажмите «…» → «Бизнес-процессы»;
3. Нажмите «Добавить процесс»;
4. Выберите условие (например, создание контакта);
5. Настройте параметры задачи;
6. Сохраните.

**Автоматические задачи из форм**

- при настройке формы включите опцию «Создавать задачу»;
- задача будет создаваться для каждой новой сделки из формы.

**Задачи по полю «День рождения»**

- добавьте поле «День рождения»;
- выберите срок создания задачи:

- в день события;
- за неделю;
- за месяц.

**Важно:**

- если до даты осталось меньше заданного срока — задача не создаётся;
- например, при настройке «за месяц» — менее 30 дней.

**Автоматическое закрытие задач**

При закрытии сделки или покупателя система предложит завершить связанные задачи.

- вы можете завершить все незавершённые задачи;
- или оставить их без изменений.
