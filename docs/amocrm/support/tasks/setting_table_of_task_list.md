**Настройка таблицы задач**

В режиме «Список» вы можете настроить отображение задач и добавить в таблицу нужные поля.

**Как открыть настройки**

1. Перейдите в раздел «Задачи»;
2. Включите режим «Список»;
3. Нажмите «Ещё» (три точки);
4. Выберите «Настройки таблицы».

**Как настроить отображение**

- перетащите нужные поля в таблицу;
- расположите их в удобном порядке;
- нажмите «Готово» для сохранения.

Это позволяет адаптировать список задач под ваши процессы и быстрее находить нужную информацию.
