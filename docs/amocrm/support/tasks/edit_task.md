# Редактирование задачи

Источник: [Редактирование задачи](https://www.amocrm.ru/support/tasks/edit_task).
Дата сохранения: 2026-10-08.
Формат: текст официальной страницы, автоматически преобразованный в Markdown.

**Редактирование задач**

Вы можете изменить параметры задачи, если условия работы изменились или была допущена ошибка.

**Где можно редактировать задачу**

- в карточке сделки, контакта, компании или покупателя;
- в разделе «Задачи».

**Редактирование в разделе «Задачи»**

- нажмите на задачу, чтобы открыть окно редактирования;
- измените параметры:

- дату и время;
- ответственного;
- тип задачи;
- текст;
- привязку к сущности.

Если задача привязана к карточке, ссылка на неё отображается в верхней части окна.

**Важно:** если привязка не отображается, возможно:

- задача не связана с сущностью;
- у вас нет доступа к карточке.

**Редактирование из карточки**

1. Откройте карточку сделки, контакта или компании;
2. Нажмите на задачу;
3. Внесите изменения;
4. Сохраните.

**Важно:** открепить задачу от карточки из самой карточки нельзя.

**Повторная постановка задачи**

- при завершении отметьте чекбокс повторной задачи;
- укажите новый срок;
- текст будет скопирован автоматически.

**Быстрое управление задачами**

**В режиме To-Do Line**

- перетаскивайте задачи между блоками;
- изменяйте сроки;
- завершайте или удаляйте задачи.

Для дополнительных действий:

- нажмите правой кнопкой мыши по задаче;
- выберите нужное действие.

**Массовые действия**

В режиме «Список» доступны:

- открытие, закрытие и удаление задач;
- смена ответственного;
- изменение срока выполнения.

**Массовое создание задач**

1. Перейдите в раздел сделок, контактов или компаний;
2. Включите режим «Список»;
3. Выберите нужные элементы;
4. Нажмите «Добавить задачу»;
5. Укажите параметры.

**Выполнение задачи**

- нажмите кнопку «Выполнить» в любом режиме отображения.

**Восстановление задач**

Доступно только администраторам:

1. Перейдите в раздел «Задачи»;
2. Откройте фильтр «Удалённые»;
3. Выберите задачи;
4. Нажмите «Восстановить».

**Важно:** задачи хранятся 30 дней, после чего удаляются безвозвратно.

**Отслеживание изменений**

Чтобы узнать, кто и когда изменил задачу:

1. Перейдите в раздел «Задачи»;
2. Включите режим «Список»;
3. Откройте «Настройки таблицы»;
4. Добавьте поля:

- «Дата изменения»;
- «Автор изменения».

Дополнительно можно отобразить:

- дату и автора создания;
- дату выполнения и автора.

Также информация доступна в разделе «Аналитика» → «Список событий».
