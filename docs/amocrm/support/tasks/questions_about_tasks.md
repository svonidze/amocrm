# Остались вопросы по задачам?

Источник: [Остались вопросы по задачам?](https://www.amocrm.ru/support/tasks/questions_about_tasks).
Дата сохранения: 2026-10-08.
Формат: текст официальной страницы, автоматически преобразованный в Markdown.

**Частые вопросы по задачам**

**Можно ли назначить несколько ответственных**

Нет. В одной задаче может быть только один ответственный.

Решение: создайте несколько одинаковых задач для разных сотрудников.

**Можно ли прикрепить файл к задаче**

Нет. Файлы можно:

- добавить ссылкой в текст задачи;
- прикрепить в примечании карточки.

**Можно ли редактировать системные типы задач**

Нет. Системные типы задач изменить нельзя.

Вы можете:

- создавать собственные типы задач;
- редактировать их (для администратора).

**Как создать свой тип задачи**

- при создании задачи выберите тип «Другой»;
- введите название.

**Почему не видны задачи других пользователей**

- по умолчанию отображаются только ваши задачи;
- используйте фильтр «Все задачи»;
- или выберите конкретного сотрудника.

**Можно ли импортировать задачи**

Нет. Импорт задач не поддерживается.

Доступно:

- синхронизация с Google Calendar;
- резервное копирование данных.

**Почему уведомления по задаче на весь день приходят утром**

Такие задачи подразумевают выполнение в течение дня, поэтому уведомление приходит в 09:00.

Если нужно другое время — укажите точный срок выполнения.

**Почему задачи в Digital Pipeline создаются не по порядку**

- порядок в интерфейсе не влияет на выполнение;
- задачи могут создаваться одновременно;
- если время совпадает — порядок может быть случайным.

Решение: задавайте разный срок выполнения.

**Может ли бесплатный пользователь работать с задачами**

Нет. Бесплатные пользователи:

- не видят задачи;
- не могут получать задачи от других пользователей.

**Можно ли связать задачу с другой задачей**

Нет, такой возможности нет.

**Как посмотреть задачи на конкретную дату**

1. Перейдите в раздел «Задачи»;
2. Выберите режим «Месяц»;
3. Найдите нужную дату;
4. Откройте задачи.

**Можно ли посмотреть просроченные задачи другого пользователя**

Да, через фильтр по пользователю.

**Важно:** отдельного фильтра только по просроченным задачам других пользователей нет.

**Почему не отображаются задачи других пользователей**

Скорее всего, у вас нет прав на просмотр связанных сущностей.

**Можно ли массово поставить задачу нескольким пользователям**

Нет. Массово можно назначить задачу только одному пользователю.

**Можно ли автоматически перевести сделку после выполнения задачи**

Нет, такой функции нет.

**Почему автоматическая задача сразу просрочена**

Причина — выбран срок «в момент создания».

Решение: используйте, например, «в конце дня».

**Можно ли настроить уведомление руководителю о просрочке**

Нет, такой возможности нет.

**Почему фильтр «Без задач» показывает элементы с задачами**

Фильтр учитывает только задачи, созданные в текущей сущности.

- если задача в сделке или компании — контакт может считаться без задач;
- проверьте привязку задачи в карточке.

Рекомендация: создавайте задачи в той сущности, по которой используете фильтр.
