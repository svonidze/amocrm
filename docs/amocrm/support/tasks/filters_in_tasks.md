**Фильтры в разделе «Задачи»**

В разделе «Задачи» вы можете использовать различные режимы отображения и фильтры для удобной работы с задачами.

**Режимы отображения**

- **To-do Line** — задачи на сегодня и завтра;
- **День** — задачи на текущий день;
- **Неделя** — задачи на текущую неделю;
- **Месяц** — задачи на месяц;
- **Список** — все задачи в виде таблицы.

**Особенности режимов**

- режим «To-do Line» подходит для краткосрочного планирования;
- режим «День» ограничивает отображение до 10 задач в одном временном слоте;
- режим «Список» удобен для поиска и редактирования.

**Предустановленные фильтры**

- **Только мои задачи** — задачи текущего пользователя;
- **Просроченные** — задачи с истёкшим сроком;
- **Выполненные** — завершённые задачи;
- **Все задачи** — задачи всех пользователей (в пределах прав доступа);
- **Удалённые** — удалённые задачи (только для администратора).

**Важно:** удалённые задачи хранятся 30 дней, после чего удаляются безвозвратно.

**Пользовательские фильтры**

- по дате (создания или закрытия);
- по типу задачи;
- по статусу (выполненные или невыполненные);
- по ответственному;
- по автору задачи.

Фильтры можно комбинировать для получения точной выборки задач.
