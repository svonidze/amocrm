**Поиск и просмотр задач**

Раздел «Задачи» позволяет отслеживать текущие, просроченные и выполненные задачи, а также управлять ими.

**Где посмотреть задачи**

- перейдите в раздел «Задачи» в левом меню;
- число в красном круге показывает:

- количество просроченных задач;
- задачи, срок которых истекает сегодня.

Просроченные задачи выделяются красным цветом.

**Режимы отображения**

- **To-do Line** — задачи по временным блокам (сегодня, неделя, будущее);
- **День** — задачи на текущий день;
- **Неделя** — задачи на текущую неделю;
- **Месяц** — задачи на месяц;
- **Список** — таблица всех задач.

**Особенности режимов**

- в режиме «День» в одном временном слоте отображается до 10 задач;
- режим «Список» подходит для поиска, редактирования и сортировки.

**Фильтры в разделе «Задачи»**

Чтобы применить фильтр:

1. Перейдите в раздел «Задачи»;
2. Нажмите «Фильтр»;
3. Выберите параметры;
4. Нажмите «Применить».

**Пользовательские фильтры**

- по времени (создание, выполнение, закрытие, «в работе»);
- по типу задачи;
- по статусу (выполненные / невыполненные);
- по ответственному;
- по автору задачи.

**Важно:** одновременно использовать системные и пользовательские фильтры нельзя.

**Системные фильтры**

- «Только мои задачи» — по умолчанию;
- «Просроченные»;
- «Выполненные»;
- «Все задачи» — с учётом прав доступа;
- «Удалённые» — только для администраторов (30 дней хранения).

**Как изменить фильтр по умолчанию**

- сохраните пользовательский фильтр;
- переместите его вверх списка.

**Фильтры задач в других разделах**

В разделах «Сделки», «Контакты», «Компании» и «Покупатели» доступны:

- **Без задач** — нет задач в текущей сущности;
- **С просроченными задачами** — есть просроченные задачи.

**Важно:** задачи из связанных сущностей не учитываются при таких фильтрах.

**Дополнительно**

- в разделах «Сделки» и «Покупатели» можно учитывать задачи связанных контактов и компаний;
- фильтры помогают находить задачи для контроля и планирования работы.
