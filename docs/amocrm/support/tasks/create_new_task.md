**Создание задач**

Задачи помогают контролировать работу с клиентами и не пропускать важные действия по сделкам, контактам и компаниям.

**Как создать задачу**

**Через карточку**

1. Откройте сделку, контакт или компанию;
2. В блоке активности выберите «Задача»;
3. Заполните параметры;
4. Нажмите «Поставить».

**Через раздел «Задачи»**

- перейдите в раздел «Задачи»;
- нажмите «Добавить задачу»;
- заполните поля и сохраните.

**Настройка задачи**

При создании можно указать:

- дату и время выполнения;
- ответственного (только одного пользователя);
- тип задачи (можно создать новый — доступно администратору);
- описание или комментарий;
- привязку к сделке, контакту, компании или покупателю;
- или оставить задачу без привязки.

**Срок выполнения**

Вы можете выбрать один из пресетов:

- через 15 минут;
- через 30 минут;
- через час;
- сегодня;
- завтра;
- до конца недели;
- через неделю;
- через месяц;
- через год.

Или указать конкретную дату и время вручную.

**Настройка времени**

- **Весь день** — задача действует в течение дня;
- **Точное время** — например, 09:15.

Особенности:

- по умолчанию уведомление приходит за 5 минут до срока;
- интервал можно изменить в профиле;
- после наступления срока задача становится просроченной.

**Особенности работы**

- если задача создана из карточки — она автоматически привязывается к ней;
- система запоминает последний выбранный срок выполнения;
- выбранный пресет применяется к следующим задачам.
