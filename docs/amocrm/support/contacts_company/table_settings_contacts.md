**Настройка таблицы контактов и компаний**

Вы можете настроить отображение колонок в списке контактов и компаний, чтобы видеть только нужные данные.

**Как открыть настройки**

1. Перейдите в раздел «Контакты» или «Компании»;
2. Нажмите на «…» в правом верхнем углу;
3. Выберите «Настройки таблицы».

**Как настроить отображение**

- перетаскивайте поля в таблицу, чтобы добавить их;
- перетаскивайте поля обратно, чтобы убрать;
- нажмите «Готово» для сохранения.

**Для всех пользователей**

- вы можете применить настройки для всей команды;
- или оставить настройки только для себя.

**Ограничения**

- поле «Наименование» удалить нельзя;
- настройка недоступна, если список пуст;
- в списке контактов нельзя вывести поля компаний (только название компании);
- в списке компаний нельзя вывести поля контактов.
