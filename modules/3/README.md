# Обработка модуля 3 «Бизнес интегратора»

Дата чтения и проверки: 2026-10-08. Подготовлены четыре файла для каждого из 25 уроков в порядке живого плейлиста: сведения страницы, локальное видео, транскрипт и конспект. Следующий модуль не обрабатывался. [Общее оглавление](../../README.md), [архив документов](../../docs/README.md).

[Материал для подготовки к экзамену](exam-prep.md) объединяет 25 уроков, четыре практические ситуации и 75 вопросов с объясненными ответами. Составлен 2026-10-09 по сохраненным источникам.

Все 25 комплектов готовы. Пробел по источнику VK у урока 13 «Упаковка бизнеса» закрыт 2026-10-09: пользователь передал две распечатки из Chrome, описание сообщества и доступные примеры прочитаны и сохранены в [архиве](../../docs/vendors/vk.com/rocket_red.md). Ограничения распечаток отмечены отдельно. Прямое чтение VK браузерным инструментом остается заблокированным; готовность урока подтверждена по предоставленным файлам.

## Проверка материалов

Все видео имеют видео- и аудиодорожку и положительную длительность по ffprobe. Журналы не содержат пропусков фрагментов. Общая длительность плейлиста 10:32:46, фактическая длительность файлов 10:33:01,129. Разница 15,129 с на весь пакет; максимальное расхождение отдельного урока 1,033 с, оно записано на странице этого урока.

Все транскрипты получены Scribe v2 с автоматическим определением языка, без диаризации. Тексты прочитаны полностью, включая начало, середину и конец. Временные метки упорядочены и находятся внутри длительности медиа. Сверка со звуком на слух не проводилась; возможны ошибки имен и терминов автоматического распознавания. Конспекты используют сведения страницы и прочитанные приложения, уточнения отделены от речи авторов.

Локальные ссылки проверены. Конспекты модуля 2 прочитаны для обоснованных связей; его файлы и прежние статусы сохранены. Видео модуля 2 переиспользуются локальными игнорируемыми ссылками. Статус «Готово» в оглавлении требует четыре непустых файла; ошибка дополнительного источника имеет приоритет над этим статусом.

## Распознавание и бюджет

Разрешенный предел: $3. Проверенный тариф Scribe v2: $0,22 за час, [официальная страница](https://elevenlabs.io/pricing/api), дата проверки 2026-10-08. По фактической длительности расчет составляет $2,3211 без налогов. Перед каждым из 25 запросов проверялся остаток разрешенного бюджета. Ответы API подтвердили суммарно 11 605 кредитов; исходный доступный баланс в Chrome был 26 339 кредитов.

Фактическое денежное списание API не предоставил, ключ не имеет User Read. Расчетная стоимость не выдается за сумму счета с налогами. Неизвестных результатов платных запросов и повторных платных запросов не было. Пополнение и смена провайдера не проводились.

## Источники и ограничения

В архиве сохранены 36 непосредственных вложений Академии: 17 PDF, 10 DOCX, 7 XLSX, BPMN XML и описание PNG. Дополнительно прочитаны три Google-материала из QR-кодов урока 12 и ценовые слайды; их копии сохранены отдельно. Формулы XLSX и кешированные результаты сохранены без пересчета. Markdown не воспроизводит геометрию схем и все оформление таблиц; оригинальные ссылки доступны в каждой копии. Визуальная проверка PDF касается таблиц, схем и показанных экранов; секретный пароль не переносился в архив.

Дополнение от 2026-10-09: две пользовательские PDF-копии VK, всего 10 страниц, объединены в один Markdown-документ. Описание, контакты, услуги и три публикации доступны для анализа упаковки. Пустые и обрезанные области не выданы за прочитанное содержимое; исходные PDF сохранены у пользователя без изменений. Дополнение не потребовало новых платных запросов распознавания.

Налоги, договорные примеры, цены и условия услуг изложены с указанием периода источника. Их актуальность как действующего законодательства или прайса на 2026-10-08 не утверждается. Противоречия видео, PDF и шаблонов перечислены в соответствующих конспектах. Технические инструкции и показатели сопоставлены с прочитанными источниками; для NPS добавлено отдельное проверенное определение Bain.

Прямые ссылки на бриф, каталог, спецификацию, BPMN и план в приложениях могут дублировать сохраненные вложения. Некоторые ссылки Teamly в PDF содержат повторенный префикс адреса; они сохранены как в источнике и не исправлены догадкой. Вложенные курсы и рекомендованные книги не запускались как новые модули. Клиентские аккаунты, группы, формы обратной связи и демонстрационные токены не использовались.
