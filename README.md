# Академия amoCRM

Материалы модулей партнерской Академии: сведения страниц, транскрипты и учебные конспекты.

Для добавления материалов используйте проектный [скил amocrm-academy](.agents/skills/amocrm-academy/SKILL.md):

- `$amocrm-academy обработай все видео модуля 2`
- `$amocrm-academy обработай видео «Воронка продаж» из модуля 2`
- `$amocrm-academy обработай <URL> через whisper`

Документы хранятся в Markdown, видео локально и вне Git. ElevenLabs используется по умолчанию, готовые транскрипты при повторном запуске сохраняются.

[Архив официальной документации и материалов уроков](docs/README.md) содержит локальные Markdown-копии со ссылками на оригиналы и датами чтения.
